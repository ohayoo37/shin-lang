Un logiciel fonctionnel. Des limites claires.

Le compilateur, la machine virtuelle, les outils web et le CMS sont disponibles sous licence MIT. Les tests et mesures reproductibles sont inclus.

Voir les tests ↗

La machine virtuelle de référence en Python est plus lente que Python sur le test de boucle simple fourni. L’exécution native/Wasm et une isolation renforcée restent à développer. Les vérifications structurelles ne garantissent pas la véracité, et les limites de taille logique ne constituent pas une isolation mémoire du système.
