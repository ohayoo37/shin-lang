WEBSITE

페이지를 만들고 원하는 곳에 게시하세요.

SHIN 함수로 HTML을 생성하고 정적 웹사이트로 내보내 원하는 호스팅에 배포하세요.

웹사이트 데모 보기 ↗ (English)

APPLICATION

브라우저와 SHIN을 연결하세요.

라우팅과 JSON API로 앱을 만듭니다. 예제 앱은 폼 입력을 SHIN으로 보내고 계산 결과를 표시합니다.

CMS

편집하고, 저장하고, 게시하세요.

인증된 편집기와 SQLite 저장소가 초안, 게시 상태, 편집 충돌 감지를 지원합니다.

개발 가이드 읽기 (영어) ↗

실험 버전입니다. 네이티브 앱 빌드, 사용자 계정, 결제, 멀티테넌트 CMS는 아직 구현되지 않았습니다. 내장 서버는 로컬 개발용입니다.

지금 사용해 보세요.

Python 3.9 이상과 Git이 필요합니다. 예제에는 API 키나 모델 다운로드가 필요하지 않습니다.

실제 AI 추론에는 별도로 실행하는 로컬 Ollama 서버를 설정할 수 있습니다.

개발 가이드 읽기 (영어) ↗
TERMINAL
git clone https://github.com/ohayoo37/shin-lang.git
cd shin-lang
python3 -m shin init my-site --template website
python3 -m shin serve my-site --port 8000
서버를 시작한 후 http://127.0.0.1:8000 을 여세요.

동작하는 소프트웨어. 명확한 한계.

컴파일러, VM, 웹 도구와 CMS를 MIT 라이선스로 공개합니다. 테스트와 재현 가능한 벤치마크도 포함됩니다.

테스트 보기 ↗

포함된 단순 반복 벤치마크에서 Python 참조 VM은 Python보다 느립니다. 네이티브/Wasm 실행과 더 강한 격리는 향후 과제입니다. 구조 검증은 내용의 진실성을 보장하지 않으며, 논리적 크기 제한은 운영체제 수준의 메모리 격리가 아닙니다.
