FROM FIRST RUN TO FIRST CONTRIBUTION

Start small. Make something.

No account or API key needed for the examples.

1. Try SHIN without installing it

Open the playground, edit the greeting and press Run SHIN. Then try “Permission + validation”: first run without the demo permission, then grant it and run again.

Open the playground → · 日本語で試す →

The browser downloads a Python/WebAssembly runtime from jsDelivr. It runs the real SHIN reference compiler and VM locally. Demo model calls echo the supplied text; they do not use a real AI model.

2. Install locally with Python 3.9+

Use a virtual environment. These commands install the pinned alpha release directly from GitHub. SHIN is not currently published on PyPI.

macOS / Linux

python3 -m venv .venv
source .venv/bin/activate
python -m pip install https://github.com/ohayoo37/shin-lang/releases/download/v0.2.0-alpha.2/shin_language-0.2.0a2-py3-none-any.whl
shin --version

Windows PowerShell

Activation is not required; use the virtual environment's Python directly.

py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install https://github.com/ohayoo37/shin-lang/releases/download/v0.2.0-alpha.2/shin_language-0.2.0a2-py3-none-any.whl
.\.venv\Scripts\python.exe -m shin --version

For a single-file download, get shin-0.2.0a2.pyz and SHA256SUMS from the release page. Verify the checksum, then run python3 shin-0.2.0a2.pyz --help. The wheel has its own WHEEL-SHA256SUMS file.

3. Build your first website

python -m shin init my-site --template website
python -m shin serve my-site --port 8000

Open http://127.0.0.1:8000. Edit my-site/app.shin, restart the server and reload the page. On Windows, replace python with .\.venv\Scripts\python.exe. Choose app, api or cms for other starter projects.

4. Tell us what happened

What did you try to build? Where did you get stuck? What would make SHIN useful to you? Share a small example in Discussions, or use the bug report form. Never include credentials or private data.

Code, native-speaker translation corrections, documentation and examples are welcome. Read the contribution guide.

SHIN is experimental. The Python reference VM is not a native compiler or an OS sandbox. The development server is for local use; accounts, payments, multi-tenant CMS and native app compilation are not implemented. Real AI inference requires separate host configuration. MIT licensed.
