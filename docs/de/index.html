Entwicklungsleitfaden lesen (Englisch) ↗

Experimentelle Version. Native App-Builds, Benutzerkonten, Zahlungen und mandantenfähige CMS sind nicht implementiert. Der enthaltene Server dient der lokalen Entwicklung.

Heute ausprobieren.

Du brauchst Python 3.9+ und Git. Die Beispiele benötigen weder einen API-Schlüssel noch einen Modelldownload.

Für echte KI-Inferenz lässt sich ein separat laufender lokaler Ollama-Server konfigurieren.

Entwicklungsleitfaden lesen (Englisch) ↗
TERMINAL
git clone https://github.com/ohayoo37/shin-lang.git
cd shin-lang
python3 -m shin init my-site --template website
python3 -m shin serve my-site --port 8000
Öffne nach dem Serverstart http://127.0.0.1:8000.

Funktionierende Software. Klare Grenzen.

Compiler, VM, Web-Werkzeuge und CMS stehen unter der MIT-Lizenz bereit. Tests und reproduzierbare Benchmarks sind enthalten.

Tests ansehen ↗

Die Python-Referenz-VM ist im mitgelieferten einfachen Schleifenbenchmark langsamer als Python. Native/Wasm-Ausführung und stärkere Isolation sind zukünftige Aufgaben. Strukturprüfungen garantieren keine inhaltliche Wahrheit; logische Größenlimits sind keine Speicherisolation durch das Betriebssystem.
