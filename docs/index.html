01 / DESIGN PRINCIPLES
01 — FLEXIBILITY

考え方を、小さな部品へ。

関数・分岐・ループ・配列・辞書。普段のプログラミングで使う道具を揃え、AIを呼ぶ処理も関数として組み立てられます。

02 — AUTHORITY

宣言だけでは、実行できない。

モデル呼び出しはコード側と実行者側の両方で許可。プログラム自身が権限を増やす仕組みはありません。

03 — BOUNDARIES

答えを、そのまま信じない。

AI出力は未検証値として受け取り、文字数やJSONの構造を確かめて利用。命令数や出力量にも上限を設けます。

02 / GET STARTED

Python 3.9以降とGitがあれば始められます。デモにAPIキーやモデルのダウンロードは不要です。

実際のAI接続には、別途起動したローカルOllamaを指定できます。

日本語ガイドを読む ↗
TERMINAL
git clone https://github.com/ohayoo37/shin-lang.git
cd shin-lang
python3 -m shin init my-site --template website
python3 -m shin serve my-site --port 8000
起動後 http://127.0.0.1:8000 を開いてください。
