Webサイトから、CMSまで。

WEBSITE

ページを作り、好きな場所へ公開。

SHINの関数でHTMLを生成し、静的サイトとして書き出して配置できます。

Webサイトのデモを見る ↗ (English)

APPLICATION

ブラウザとSHINをつなぐ。

ルーティングとJSON APIでアプリを構築。入力から計算結果の表示まで動く雛形を用意しました。

CMS

編集して、保存して、公開。

認証付き編集画面とSQLite保存。下書き・公開の切替と、編集競合の検出に対応します。
