Versão experimental. A geração de aplicativos nativos, contas de usuário, pagamentos e CMS multitenant não estão implementados. O servidor incluído é para desenvolvimento local.

Experimente hoje.

Você precisa do Python 3.9+ e do Git. Os exemplos não exigem chave de API nem download de modelos.

Para inferência real de IA, configure um servidor Ollama local executado separadamente.

Ler o guia de desenvolvimento (inglês) ↗
TERMINAL
git clone https://github.com/ohayoo37/shin-lang.git
cd shin-lang
python3 -m shin init my-site --template website
python3 -m shin serve my-site --port 8000
Após iniciar o servidor, abra http://127.0.0.1:8000.

Software funcional. Limites claros.

O compilador, a VM, as ferramentas web e o CMS estão disponíveis sob a licença MIT. Testes e benchmarks reproduzíveis estão incluídos.

Ver os testes ↗

A VM de referência em Python é mais lenta que Python no benchmark de laço simples incluído. Execução nativa/Wasm e isolamento mais forte são tarefas futuras. Verificações estruturais não garantem veracidade, e limites de tamanho lógico não são isolamento de memória do sistema operacional.
