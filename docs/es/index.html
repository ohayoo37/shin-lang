Leer la guía de desarrollo (inglés) ↗

Versión experimental. No incluye compilación de aplicaciones nativas, cuentas de usuario, pagos ni CMS multiinquilino. El servidor incluido es para desarrollo local.

Pruébalo hoy.

Necesitas Python 3.9+ y Git. Los ejemplos no requieren claves de API ni descargar modelos.

Para usar IA real, configura un servidor local de Ollama que se ejecute por separado.

Leer la guía de desarrollo (inglés) ↗
TERMINAL
git clone https://github.com/ohayoo37/shin-lang.git
cd shin-lang
python3 -m shin init my-site --template website
python3 -m shin serve my-site --port 8000
Después de iniciar el servidor, abre http://127.0.0.1:8000.

Ver las pruebas ↗

La máquina virtual de referencia en Python es más lenta que Python en la prueba de bucle simple incluida. La ejecución nativa/Wasm y un aislamiento más fuerte quedan para el futuro. Las comprobaciones estructurales no garantizan la veracidad, y los límites de tamaño lógico no aíslan la memoria del sistema operativo.
